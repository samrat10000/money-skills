# AGENTS.md (Codex, Cursor, Gemini, any agent)

When the user asks for a 2D / anime / toon / motion-graphics story reel, an episode or a shot, or types `/anime-reel`:

1. Read `anime-reel/SKILL.md` completely, then every file in its reading order
   (`DISCIPLINE.md`, `RULEBOOK.md`, `QA.md`, `STORY.md`, `PIPELINE.md`, `CHARACTERS.md`, `EDIT.md`, `SOUND.md`, `ENVIRONMENT.md`).
2. Follow the phases and gates exactly. Evidence goes in `QA_LOG.md` (contact sheets and crops you opened, `pixel_stats.py` numbers).
3. After building ANY element, run its checklist and the Director's eye pass; 3-6 passes per shot before showing it.
4. One perfect shot first, then write `SHOT_RULES.md`; every director note becomes a rule for all later shots.
5. Keep `REEL_STATE.md`, `DECISIONS.md` and `WORKING.md` updated so any agent can continue the work.
