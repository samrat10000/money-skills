# AGENTS.md (Codex, Cursor, Gemini, any agent)

This repo holds several skill packs, one per folder (see README.md). When the user asks for a task one of
them covers, open that folder's AGENTS.md and follow it exactly. Example: a teaser or trailer-style reel,
or `/teaser`, means `make-teaser/AGENTS.md` -> `make-teaser/teaser/SKILL.md`.
A 2D / anime / toon reel, episode or shot, or `/motion2d`, means `make-motion2d/AGENTS.md` -> `make-motion2d/motion2d/SKILL.md`.
A Night Terror episode, shot, creature or scene (or the same 3D ink horror style), or `/terror-night`, means `make-terror-night/AGENTS.md` -> `make-terror-night/terror-night/SKILL.md`.
