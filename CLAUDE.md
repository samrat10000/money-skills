# CLAUDE.md

This repo holds several skill packs, one per folder (see README.md). When the user asks for a task one of
them covers, open that folder's AGENTS.md and follow it exactly. Example: a teaser or trailer-style reel,
or `/teaser`, means `make-teaser/AGENTS.md` -> `make-teaser/teaser/SKILL.md`. A 2D / anime / toon story reel, an episode or a shot, or `/anime-reel`, means `make-anime-reel/AGENTS.md` -> `make-anime-reel/anime-reel/SKILL.md`.
