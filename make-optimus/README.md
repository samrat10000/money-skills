# make-optimus
**Optimus**: get the same extreme production quality for far fewer tokens. Ten rules (numbers before pictures, probes
that print, assets built once, one plan per pass, overnight queues, event-driven waiting, small-model helpers, narrow
reads, state on disk, short replies), the standard project folder layout, a helper-brief template, and `qa_auto.py`
(automatic frame/clip/episode QA). Works under every production skill in this repo. Install: `install/install.sh` or
`install/install.ps1`. Built from Night Terror Ep1 (Nov 2026); update it after every project.
