# AGENTS.md (make-optimus)
Optimus is the token-saving operating layer for EVERY production in this repo (terror-night, teaser, motion2d, new ones).
When working on any production, or when the user types `/optimus`, asks to save tokens, or to organize a project:
1. Read `optimus/SKILL.md` (the 10 rules), then `optimus/FOLDERS.md` and `optimus/HELPERS.md` as needed.
2. Follow the production skill for WHAT good looks like and Optimus for HOW to get there cheaply. Quality wins ties.
3. Run `optimus/scripts/qa_auto.py` on every finished render before opening any image.
